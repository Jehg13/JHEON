# JHEON

Portfolio built with React, TypeScript, Vite, Tailwind CSS, Three.js,
React Three Fiber, Drei, Framer Motion, and GSAP ScrollTrigger.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`, then preview it with
`npm run preview`.

## Add a project

Add an entry to `src/data/projects.ts`. Project images, descriptions, technology
tags, GitHub links, demos, and APKs are optional; keep them empty until verified
project details are available. Set `featured` to show a project in the large
showcase before the editorial project grid.

The technology network is labelled as the portfolio toolset; it does not
represent unverified technologies used in the featured projects.
